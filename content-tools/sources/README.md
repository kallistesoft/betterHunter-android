# Source manuals (not committed)

Put the official study PDFs here. They are copyrighted, so this folder is gitignored.
The pipeline only uses them to extract facts; questions are written in original wording.

Expected files are listed in `content/sources.json`, e.g.:

- `cfsc_fr.pdf`: *Cours canadien de sécurité dans le maniement des armes à feu*, student handbook (RCMP, French)
- `icaf_fr.pdf`: ICAF course manual (FédéCP / Québec)
